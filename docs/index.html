技术架构

基于 Electron 构建，核心亮点

视频播放

Aliyun VOD playauth → STS 凭证 → Signature V1 签名 → MP4 地址 → HTML5 video

本地缓存

local-video:// 协议 + HTTP Range (206) 支持，自由拖拽进度条

字幕提取

ffmpeg 提取音频 → faster-whisper (GPU) / whisper.cpp → SRT/VTT 字幕

安全架构

contextBridge 安全预加载 + 主进程统一 IPC 代理

常见问题

快速解答你可能关心的问题

需要会员吗？
不需要。只需你有博学谷账号能正常登录获取 Cookie 即可使用全部功能。
安全吗？
Cookie 仅存储在本地，所有请求通过本地代理转发，不经过任何第三方服务器。开源代码可审计。
支持哪些平台？
Windows、macOS、Linux 全平台支持，提供对应安装包。
AI 解读怎么用？
配置任意 OpenAI 格式 API（如 OpenAI、智谱、Moonshot 等），即可对视频内容多轮追问。
字幕准确吗？
使用 faster-whisper / whisper.cpp 中文语音识别，对于清晰人声课程准确率较高。
